# Contributing to Rewatch

Thank you for taking the time to contribute.

## Getting help

- Open a [GitHub issue](https://github.com/naouflex/rewatch/issues) for bugs and feature requests.
- Use [GitHub Discussions](https://github.com/naouflex/rewatch/discussions) for questions and ideas.

## Development

See `DEPLOY.md` and `setup/README.md` for local development setup.

## Documentation

Product help is part of the app at `/help`. Articles live in `client/app/pages/help/content/`.

## Security

Please report security issues to maintainers@naoufel.io.
