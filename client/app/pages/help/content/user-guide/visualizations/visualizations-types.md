A table is the default view for any query result. Beyond that, Rewatch supports a long list of visualization types.

| Type | Description |
| --- | --- |
| **Boxplot** | Distribution summary across grouped categories. |
| **Chart (Line, Bar, Area, Pie, Scatter)** | The general-purpose chart type with eight built-in forms; see [Chart visualizations](/help/user-guide/visualizations/chart-visualizations). |
| **Cohort** | Compare cohorts over time; see [Cohort visualizations](/help/user-guide/visualizations/cohort-visualizations). |
| **Counter** | A single big number, optionally compared to a target. |
| **Funnel** | Two-column step / value visualization; see [Funnel visualizations](/help/user-guide/visualizations/funnel-visualizations). |
| **Map (Marker)** | Plot points on a map by latitude / longitude. |
| **Map (Choropleth)** | Shade regions of the world by a metric. |
| **Pivot Table** | Drag-and-drop equivalent of `PIVOT` / `GROUP BY`; see [Pivot tables](/help/user-guide/visualizations/pivot-table). |
| **Sankey** | Flow diagram for relationships between sets. |
| **Sunburst** | Hierarchical relationship visualization. |
| **Table** | Default; reorder, hide and format columns - see [Table visualization options](/help/user-guide/visualizations/table-options). |
| **Word Cloud** | Frequency-weighted word cloud from a text column. |

For deep-dives into chart subtypes (line vs bar vs area vs scatter etc.) start with [Chart visualizations](/help/user-guide/visualizations/chart-visualizations).
