A visualization turns rows of data into something you can read at a glance. Rewatch ships with a long list of chart types, each with sensible defaults and fine-grained tabs for everything else.

The pages in this group cover the visualization stack end to end:

-   [Visualizations how-to](/help/user-guide/visualizations/visualizations-how-to) - create, edit, embed and download visualizations.
-   [Visualization types](/help/user-guide/visualizations/visualizations-types) - reference of every chart type.
-   [Chart visualizations](/help/user-guide/visualizations/chart-visualizations) - line, bar, area, pie, scatter, bubble, heatmap and box plots.
-   [Cohort visualizations](/help/user-guide/visualizations/cohort-visualizations) - track grouped behaviour over time.
-   [Funnel visualizations](/help/user-guide/visualizations/funnel-visualizations) - two-column step / value visualization.
-   [Pivot tables](/help/user-guide/visualizations/pivot-table) - aggregate data with drag-and-drop instead of SQL.
-   [Table visualization options](/help/user-guide/visualizations/table-options) - reorder, hide, format columns; render JSON, images and links.
-   [Formatting numbers](/help/user-guide/visualizations/formatting-numbers) - numeral.js format strings reference.
