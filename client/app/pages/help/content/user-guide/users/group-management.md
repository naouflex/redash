Users can be members of one or more groups. Each new user joins the `Default` group automatically. Members of `Admin` can create groups, add and remove members, associate groups with data sources, and disable users entirely.

## Creating and editing groups

Only members of `Admin` can create or edit groups. Open _Settings → Groups_ and click _New Group_. Pick a name, then add users by typing their names. Click an existing group on the list to rename it, change its members, or change which data sources it has access to.

The `Default` and `Admin` groups can't be deleted.

![Create or edit a group](/content/help/assets/admin-groups/admin-groups-00-creat_new_group_bis.gif)

## Making admins

Add a user to the `Admin` group to give them admin privileges (which include modifying data sources, changing groups and permissions, disabling users, and granting admin to other users). Remove them from the group to revoke admin.

## Disabling users

Admins can disable a user from _Settings → Users_. Find the user and click _Disable_; they can no longer sign in until reactivated.

![Disable a user](/content/help/assets/admin-groups/admin-groups-01-disable_user.gif)

To re-enable a user, switch to the _Disabled_ tab on the same screen and click _Enable_. The _Disabled_ tab only appears once at least one user has been disabled.
