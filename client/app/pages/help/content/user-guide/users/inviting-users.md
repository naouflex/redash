Only admins can invite new users. To invite someone, open _Settings → Users_ and click _New User_.

Fill in their name and email. They receive an invite email and are prompted to set up an account (or sign in via SSO if you've configured it).

![Inviting users](/content/help/assets/admin-invite/admin-invite-00-new_user.gif)

To add a user to an existing group, open _Settings → Groups_, pick the group, and start typing the user's name in the member field.

![Add a user to an existing group](/content/help/assets/admin-invite/admin-invite-01-add_users_group.gif)

Once invited, users land in the `Default` group automatically. From there, mix and match memberships per [Permissions & Groups](/help/user-guide/users/permissions-groups).
